RMVM 7 - LEIA-ME
================

Esta e a versao SEM executavel.
Nao existe nenhum .exe de arranque nesta pasta.

As dependencias do projeto (node_modules) ja vao incluidas.
Nao e preciso correr "npm install" para abrir o site.

A base de dados tambem ja vai incluida (SQLite). Nao precisa de
instalar MariaDB nem MySQL. Os dados ficam em dados\rmvm.db.

Para funcionar, este computador precisa apenas de ter:

   1. Node.js 20 ou mais recente

Se ainda nao tem o Node.js, siga o ficheiro:

   INSTALAR.txt

Se ja tem o Node.js, abra a pasta do site, abra o cmd nessa pasta
e escreva:

   npm run dev

Se estiver no PowerShell e o comando for bloqueado:

   npm.cmd run dev

Tambem pode usar sempre:

   node scripts\dev.js

O navegador abre sozinho em http://localhost:5173
